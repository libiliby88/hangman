# Hangman Game

A classic Hangman word guessing game built with Python and Tkinter.

## Features

- Graphical user interface with a dark theme
- Visual hangman drawing that progresses with wrong guesses
- Interactive keyboard for letter selection
- Word list with programming-related terms
- Win/lose detection with game over messages
- New game button to restart

## How to Run

1. Make sure you have Python installed (Tkinter is included with standard Python installations)
2. Navigate to the hangman directory:
   ```bash
   cd hangman
   ```
3. Run the game:
   ```bash
   python hangman.py
   ```

## How to Play

1. Click on letters to guess the secret word
2. Green letters are correct guesses
3. Red letters are wrong guesses
4. The hangman drawing progresses with each wrong guess
5. You have 6 wrong guesses before losing
6. Click "New Game" to start over with a new word

## Requirements

- Python 3.x
- Tkinter (usually included with Python)

No additional packages need to be installed!
